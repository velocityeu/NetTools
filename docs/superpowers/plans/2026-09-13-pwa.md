# Velocity NetTools PWA Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent modules and review. Track completion here.

**Goal:** Deliver the approved installable subnet and public-IP PWA linked from the learning centre.
**Architecture:** Shared C++ arithmetic compiled with Emscripten, exposed through a typed JSON boundary in a cancellable worker. Static HTML/CSS/ES modules own UI, explicit saved plans, HTTPS checks and scoped offline caching.
**Tech Stack:** C++20, Emscripten, browser ES modules, Node test runner, Playwright, Python build scripts, GitHub Pages.
**Spec:** docs/design/pwa-design.md (revision 02, approved 13 September 2026).

## Global constraints
- VEU publication identity; exact corporate assets; no credentials or personal paths published.
- Phone/tablet/desktop equal priority; iOS/iPadOS 17+; no account or runtime installation.
- All integer counts exact; browser calculations use the existing C++ core.
- Named plans saved explicitly, drafts session-only unless explicitly saved.
- Public IP after opt-in on launch or manual request; separate families, cancellation and no cache.
- Pins and reservations included; Apply is all-or-nothing and independent of Save.
